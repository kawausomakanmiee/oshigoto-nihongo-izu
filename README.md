# おしごと日本語｜IZU β

伊豆賀茂地域の旅館・ホテルで働く人のための、スマートフォン向け日本語学習アプリです。3コース・30語を収録し、日本語・インドネシア語の意味と例文、ふりがな、音声、4択クイズ、復習、端末内の学習記録に対応しています。新人研修への活用を想定したβ版です。

## ローカルで使う

追加のアプリ用パッケージやビルドは不要です。リポジトリ内で次を実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザでローカルサーバーを開きます。`index.html` を直接開くこともできますが、学習記録の保存動作がブラウザごとに異なるため、HTTPでの利用を推奨します。`index.html`、`styles.css`、`data.js`、`app.js` は同じディレクトリに置きます。外部API・CDN・認証は不要です。この変更にはデプロイやGitHub Pagesの公開設定は含みません。

## 学習機能

- 「単語カード」でコースを選び、意味と例文を学びます。「覚えた」またはクイズの正解で学習済みになります。
- 説明言語とふりがな表示の設定も端末内に保存します。
- 「4択クイズ」ではコースごとに出題順を変えます。回答後の言語変更でも回答は確定したままです。終了時に正解数を表示します。
- 間違えた単語は復習リストに保存します。「復習」は選択中のコースで絞り込み、正解した単語をリストから外します。
- 「下膳（げぜん）」には「下げ膳（さげぜん）」「お皿を下げてください」を併記し、別表現の音声も聞けます。クイズでも両方の語を示します。同じ概念として記録するため、語数は30語のままです。
- 学習記録の消去には確認が必要です。言語・ふりがな設定は保持します。
- 旧版と同じ保存キー `izu-japanese-beta-v1` と単語IDを使用します。同じブラウザ・オリジンで既存記録を引き継ぎます。重複IDや不正IDを除外し、壊れたJSONでも画面を起動します。保存できない場合は画面に通知します。端末間同期はありません。

## 教材の編集・言語の追加

教材は `data.js`、動作は `app.js`、表示は `index.html` と `styles.css` に分けています。

各語は固定の `id`、`course`、`word`、`reading`、`meaning`、`sentence`、`translated`、`aliases` を持ちます。既存IDを変更・再利用すると学習記録が別の語を指すため、変更しないでください。

日本語の例文は `予約[よやく]を確認[かくにん]してください。` のように、漢字部分ごとに読みを指定します。画面ではruby要素に変換し、音声には読みを渡します。ひらがなや送りがなは括弧の外に置きます。単語・別表現の読みは `reading` に指定します。`translated.ja` は意味の繰り返しではなく、例文全体をやさしい日本語で言い換えます。

ベトナム語・ミャンマー語は、翻訳をレビューした後に次の手順で追加できます。未翻訳の言語を利用可能として表示しないでください。

1. `languages` に `{code: 'vi', label: 'Tiếng Việt'}` または `{code: 'my', label: 'မြန်မာဘာသာ'}` を追加します。
2. 各語の `meaning` と `translated` に同じ言語コードの翻訳を追加します。
3. 別表現のある語は `note` と `aliasTranslation` にも翻訳を追加します。

欠けた翻訳はやさしい日本語にフォールバックします。言語選択は教材の登録から生成するため、クイズ処理を変更する必要はありません。画面の操作案内は日本語を基本とし、主な案内にインドネシア語を併記しています。画面全体の多言語UI化は別途対応が必要です。

## 動作テスト

Node.js、Python、PythonのPlaywright、Chromiumが必要です。準備済みクラウド環境には導入済みです。別の環境ではPlaywrightをインストールし、`tests/browser.py` のChromiumパス（`/usr/bin/chromium`）を実環境に合わせてください。アプリ自体にはこれらのテスト用依存関係は不要です。

```sh
node --check app.js
node --check data.js
python3 tests/browser.py
```

ブラウザテストは専用の一時HTTPサーバーと新しいブラウザコンテキストを作り、利用者の記録は変更しません。7件のテストで次を確認します。

- 30語のID・各コース10語・翻訳・例文の全漢字のふりがな・別表現・320/375/390/430/768px幅
- 旧記録と不正IDの処理、コース別復習、言語・ふりがな設定の保持
- クイズ4択、言語変更時の再回答防止、誤答から復習・正解・完了まで
- 10問連続回答、学習記録保存、消去の取消・確定、復習画面からの消去
- 壊れた保存データと保存拒否時の動作
- 音声APIに渡す読み・日本語指定、音声エラーと非対応ブラウザの案内
- 将来の翻訳不足時のフォールバック

音声APIのテストでは再生処理を差し替えています。実際の発音、音量、端末の日本語音声の有無は対象端末で確認してください。

## 教材としての確認事項

インドネシア語の曖昧な表現と例文を見直しました。正式な研修利用前には、インドネシア語母語話者と宿泊業実務者による確認が必要です。現場ごとの呼び方や手順を優先してください。施設の安全教育・実技確認の代替ではありません。
