# おしごと日本語｜IZU β

スマートフォン向けの静的Webアプリ。3コース30語、日本語・インドネシア語の説明、ふりがな切り替え、端末の音声合成、4択、復習、localStorageによる進捗保存に対応。

## 使い方
`index.html`をブラウザで開いてください。公開する場合は`index.html`と`app.js`を同じディレクトリに置いて、静的ホスティングにアップロードします。

## 注意
- 開発中のβ版です。翻訳は公開前にインドネシア語母語話者と宿泊業実務者による確認を推奨します。
- 読み上げは端末の音声合成を使います。音声品質は端末依存です。
- 例文のふりがなは簡易辞書方式です。未登録の漢字には表示されない場合があります。正式版では全例文をルビ付き構造化データにすることを推奨します。
- 進捗はブラウザ内に保存され、端末間では同期されません。
- SNS公開時には公開URLを知る人がアクセスできる状態になるため、公開範囲を確認してください。
- 施設の安全教育や実技確認の代替ではありません。
