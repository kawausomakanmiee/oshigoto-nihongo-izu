# おしごと日本語｜IZU β

伊豆賀茂地域の旅館・ホテルで働く人のための、スマートフォン向け日本語学習アプリです。6場面の会話を学習の入口とし、補助教材として3コース・30語を収録しています。日本語・インドネシア語の意味と例文、ふりがな、音声、4択クイズ、復習、端末内の学習記録に対応しています。新人研修への活用を想定したβ版です。

## ローカルで使う

追加のアプリ用パッケージやビルドは不要です。リポジトリ内で次を実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザでローカルサーバーを開きます。`index.html` を直接開くこともできますが、学習記録の保存動作がブラウザごとに異なるため、HTTPでの利用を推奨します。`index.html`、`styles.css`、`data.js`、`app.js`、`lessons-data.js`、`lessons.js` は同じディレクトリに置きます。外部API・CDN・認証は不要です。この変更にはデプロイやGitHub Pagesの公開設定は含みません。

## 会話レッスン（最初に表示）

日本人の先輩と外国人スタッフのやりとりを、次の6場面・各3往復（6発話）で練習します。

1. 仕事の指示がわからないとき
2. 客室清掃が終わったとき
3. お客様の忘れ物を発見したとき
4. レストランで配膳の指示を受けたとき
5. 客室設備の故障を発見したとき
6. 体調が悪く、先輩に相談するとき

話者別の会話を読み、各発話の「きく」で日本語音声を聞けます。漢字のふりがな、説明言語、日本語の声と速度は既存の設定を共有します。音声の状態やエラーは、押した発話の隣に表示します。声に出して練習する教材ですが、マイク録音や発音採点は行いません。

「返事を練習する」から場面別4択クイズ（各1問）に進みます。報告の具体性、事実と推測、指示の確認、作業の引き継ぎなどを考える選択肢です。出題ごとに選択肢を並べ替え、正答・誤答それぞれの理由と適切な返答例を示します。回答後の言語変更で再回答できません。「もう一度」で練習し直せます。

正解後に「この会話を完了する」を押すと完了状況を保存します。閲覧・音声再生だけでは完了にはしません。完了後に再練習して間違えても、以前の完了記録は保持します。今回の画面に戻って正解するまでは、新たな完了操作はできません。

重要単語の意味を会話内に表示し、「カード」から既存の単語カードへ移動できます。「会話に戻る」で直前の会話と回答状態へ戻れます。会話を助ける30語のIDは変更せず、新語カードは増やしていません。場面固有の表現は会話内の「伝え方のポイント」でも補足しています。

インドネシア語訳と日本語会話は暫定教材です。母語話者および宿泊施設の実務者による確認が必要で、画面にもその旨を表示しています。忘れ物・設備異常・体調不良への対応は施設の手順を優先してください。

### 会話記録と単語記録の分離

- 単語：従来の `izu-japanese-beta-v1`。30語のIDと学習記録・表示・音声設定を維持します。
- 会話：新しい `izu-conversations-v1`。完了したレッスンIDと、問題ごとの回答回数・正解回数・最後の選択肢IDを保存します。全回答の履歴や録音は保存しません。
- 会話の完了・回答・記録消去では単語の保存キーに書き込みません。共有設定の変更や単語の「覚えた」は従来どおり単語側に保存します。
- 「会話記録の管理」の消去は会話のみ、従来の消去ボタンは単語のみです。どちらも確認ダイアログがあります。
- 壊れた会話記録は通知して練習を開始できます。保存できない場合は通知し、その画面では練習を続けられます。記録は同じブラウザ・オリジン内のみで、同期されません。

### 会話データと将来の拡張

`lessons-data.js` が教材、`lessons.js` が会話一覧・発話表示・単語連携・返答クイズ・記録処理です。教材はレッスンID、対象者 `audience`、目的 `goal`、学習技能 `skills`、話者 `speakers`、発話 `dialogue`、既存語の `vocabIds`、場面クイズ `quiz` を分離しています。問題・選択肢にも固定IDを持たせ、配列順を変えても採点や保存結果を維持します。意味や例文と同じく言語コード別の翻訳を持ち、未翻訳の場合は日本語にフォールバックします。

対象者レジストリには、現在有効な `international-staff` と、未有効の `japanese-staff` を定義しています。後者に「やさしい日本語での指示」「異文化理解」「相談しやすい職場づくり」の将来トピックだけを置き、教材や切替UIは追加していません。現在の画面は `international-staff` の教材だけを選びます。将来、対象者切替UIと教材・検証を追加できます。

新しい教材ではレッスン・問題・選択肢IDを再利用しないでください。採点内容を変える改訂では問題IDも変更し、既存結果と混同しないようにします。現行版は1場面1問で、複数問題への画面拡張は別途必要です。

## 学習機能

- 「単語カード」でコースを選び、意味と例文を学びます。「覚えた」またはクイズの正解で学習済みになります。
- 説明言語とふりがな表示の設定も端末内に保存します。
- 「4択クイズ」ではコースごとに出題順を変えます。回答後の言語変更でも回答は確定したままです。終了時に正解数を表示します。
- 間違えた単語は復習リストに保存します。「復習」は選択中のコースで絞り込み、正解した単語をリストから外します。
- 「下膳（げぜん）」には「下げ膳（さげぜん）」「お皿を下げてください」を併記し、別表現の音声も聞けます。クイズでも両方の語を示します。同じ概念として記録するため、語数は30語のままです。
- 学習記録の消去には確認が必要です。言語・ふりがな設定は保持します。
- 旧版と同じ保存キー `izu-japanese-beta-v1` と単語IDを使用します。同じブラウザ・オリジンで既存記録を引き継ぎます。重複IDや不正IDを除外し、壊れたJSONでも画面を起動します。保存できない場合は画面に通知します。端末間同期はありません。

## 音声の設定

「音声の設定」で端末が提供する日本語の声を選べます。速度は標準（1.0）が初期値で、ゆっくり（0.85）にも切り替えられます。設定は学習記録と同じ場所に保存します。「自動」は日本語の既定の声、または利用可能な最初の日本語音声を選びます。

日本語音声の一覧が遅れて届く場合は最大1.5秒待ちます。日本語音声が見つからなければ再生せず、端末での音声追加を案内します。外国語の既定音声で日本語を読ませることはしません。ブラウザによっては、端末に日本語音声があっても一覧に公開されない場合があります。

旧版の「全文をかな化して0.83倍で読む」方式をやめ、漢字かな交じりの文章と標準速度を使います。ただし、Web Speech APIの声質・アクセント・専門用語の読みは端末とブラウザに依存します。読みが異なる場合は別の日本語の声を試してください。研修用の発音を固定するには、今後、人が確認した録音などの音声教材が必要です。録音や外部の音声生成サービスは今回追加していません。

## 教材の編集・言語の追加

教材は `data.js`、動作は `app.js`、表示は `index.html` と `styles.css` に分けています。

各語は固定の `id`、`course`、`word`、`reading`、`meaning`、`sentence`、`translated`、`aliases` を持ちます。既存IDを変更・再利用すると学習記録が別の語を指すため、変更しないでください。

日本語の例文は `予約[よやく]を確認[かくにん]してください。` のように、漢字部分ごとに読みを指定します。画面ではruby要素に変換します。例文の音声には、ふりがなの注記だけを除いた漢字かな交じりの文章を渡し、音声エンジンが文脈から抑揚を付けられるようにします。ひらがなや送りがなは括弧の外に置きます。単語・別表現の読みは `reading` に指定します。`translated.ja` は意味の繰り返しではなく、例文全体をやさしい日本語で言い換えます。

ベトナム語・ミャンマー語は、翻訳をレビューした後に次の手順で追加できます。未翻訳の言語を利用可能として表示しないでください。

1. `languages` に `{code: 'vi', label: 'Tiếng Việt'}` または `{code: 'my', label: 'မြန်မာဘာသာ'}` を追加します。
2. 各語の `meaning` と `translated` に同じ言語コードの翻訳を追加します。
3. 別表現のある語は `note` と `aliasTranslation` にも翻訳を追加します。

欠けた翻訳はやさしい日本語にフォールバックします。言語選択は教材の登録から生成するため、クイズ処理を変更する必要はありません。画面の操作案内は日本語を基本とし、主な案内にインドネシア語を併記しています。画面全体の多言語UI化は別途対応が必要です。

## 動作テスト

Node.js、Python、PythonのPlaywright、Chromiumが必要です。準備済みクラウド環境には導入済みです。別の環境ではPlaywrightをインストールし、`tests/browser.py` のChromiumパス（`/usr/bin/chromium`）を実環境に合わせてください。アプリ自体にはこれらのテスト用依存関係は不要です。

```sh
node --check app.js
node --check data.js
node --check lessons-data.js
node --check lessons.js
python3 tests/browser.py
```

ブラウザテストは専用の一時HTTPサーバーと新しいブラウザコンテキストを作り、利用者の記録は変更しません。13件のテストで次を確認します。

- 30語のID・各コース10語・翻訳・例文の全漢字のふりがな・別表現・320/375/390/430/768px幅
- 旧記録と不正IDの処理、コース別復習、言語・ふりがな設定の保持
- クイズ4択、言語変更時の再回答防止、誤答から復習・正解・完了まで
- 10問連続回答、学習記録保存、消去の取消・確定、復習画面からの消去
- 壊れた保存データと保存拒否時の動作
- 音声APIへ漢字かな交じりの文を渡すこと、日本語の声のみを選ぶこと、音声エラーと非対応ブラウザの案内
- 声と速度の選択・保存、遅れて読み込まれる声の検出、移動後の再生キャンセル
- 将来の翻訳不足時のフォールバック
- 6場面・各6発話のふりがな／訳、全24選択肢の説明、6場面の正解・完了・再読込
- 会話→既存単語カード→同じ会話への復帰、言語切替時の回答確定、ふりがな切替
- 発話ごとの音声要求と音声なしの案内、狭い画面でのレイアウト
- 会話記録の破損・保存拒否、会話と単語の消去の分離、会話操作による旧記録の非破壊

音声APIのテストでは再生処理を差し替えています。実際の発音、音量、端末の日本語音声の有無は対象端末で確認してください。

## 教材としての確認事項

インドネシア語の曖昧な表現と例文を見直しました。正式な研修利用前には、インドネシア語母語話者と宿泊業実務者による確認が必要です。現場ごとの呼び方や手順を優先してください。施設の安全教育・実技確認の代替ではありません。
